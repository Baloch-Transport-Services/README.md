# Baloch Transport Services

We are a company dedicated to providing top-notch transportation solutions, offering services for both passenger and cargo transport. Our GitHub repositories include various tools, services, and utilities that help us streamline operations and provide the best solutions to our customers.

## About Us
Baloch Transport Services has been serving the transportation industry with reliable, efficient, and innovative solutions. Our goal is to revolutionize the transportation experience through seamless technology, making it easier and more efficient for our clients.

## Our Repositories
Here is a list of our private repositories, each playing a vital role in the management of our services and operations:

### 1. **Website**
- **Description**: This repository contains the code for our company's official website, which serves as the online presence for Baloch Transport Services. It features a user-friendly interface for online bookings and detailed company information.
- **Tech Stack**: PHP Laravel, Vue.js

### 2. **ERP Software**
- **Description**: The ERP Software repository houses the complete code for our Enterprise Resource Planning system, designed to manage every aspect of the company. From accounting to HR management, route planning to fleet management, this system streamlines operations and ensures smooth running of the entire company.
- **Tech Stack**: PHP Laravel, Vue.js

### 3. **Android Application**
- **Description**: This repository contains the complete source code for our Android application, enabling customers to make online bookings for transport services via their mobile devices. The app is designed to be intuitive, offering an easy way for users to book and track their transportation needs.
- **Tech Stack**: Kotlin

### 4. **iOS Application**
- **Description**: This repository contains the full code for our iOS application, providing the same seamless experience as the Android version but for iPhone and iPad users. It allows users to book transportation services and manage their requests directly from their Apple devices.
- **Tech Stack**: Swift

### 5. **Cargo & Logistics Software**
- **Description**: This repository is dedicated to our Cargo and Logistics management software. It supports the online booking and management of cargo transport services, providing a complete platform for customers to manage their logistics and shipping needs.
- **Tech Stack**: PHP CodeIgniter
